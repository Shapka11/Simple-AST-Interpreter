# Simple AST Interpreter

Три варианта выполнения программы на C# / .NET 10:

- `SimpleASTInterpreter` — прямое выполнение JSON AST.
- `SimpleASTInterpreter.Instructions` — выполнение JSON-инструкций стековой машиной.
- `SimpleAstProgramToInstructions` — компиляция JSON AST в инструкции, печать JSON команд и их выполнение.

Узлы AST и команды обходятся через Visitor. Числа, строки, массивы и S-выражения используют общую модель `RuntimeValue`.

## Команды и возможности языка

| Возможность | JSON AST | Команды машины |
| --- | --- | --- |
| Ввод и вывод | `read`, `write` | `READ`, `WRITE` |
| Переменные и присваивание | `var`, `assn` | `LD`, `ST` |
| Числа и бинарные операции | `const`, `binop` | `CONST`, `BINOP` |
| Условия и циклы | `if`, `while`, `do`, `seq`, `skip` | `LABEL`, `JMP`, `JZ`, `JNZ` |
| Массивы | `array` | `ARRAY count` |
| Строки | `string` | `STRING text` |
| Длина | `length` | `LENGTH` |
| Индексация | `elem`, `index` | `ELEM` |
| Присваивание элементу | `set` с полями `dst`, `idx`, `value` | `SET` |
| Конструкторы и списки | `sexp`, `args` | `SEXP name count` |

Добавлена сквозная поддержка последних шести команд: парсер, выполнение, генератор и запись JSON. Исправлен разбор объектных инструкций в `InstructionParser`.

Сайты [eval.html](https://dboulytchev.github.io/eval.html) и [sm.html](https://dboulytchev.github.io/sm.html) преобразуют `for` в последовательность и `while`, `elif` — во вложенный `if`, составные присваивания — в обычные присваивания с бинарной операцией. Символы становятся числовыми константами. Списки `{1, 2}` и операция `:` становятся конструкторами `cons` / `nil`. Эти возможности работают через базовые узлы AST, без отдельных классов для каждого синтаксического сокращения.

Строки изменяемые; индексация возвращает код байта UTF-8, присваивание принимает число от 0 до 255. У конструкторов доступны длина, чтение и изменение аргументов по индексу. Массивы сравниваются по содержимому: сначала длина, затем элементы; строки — лексикографически. Сравнение конструкторов и разных типов, как в эталоне, не поддерживается. `&&` и `!!` вычисляют оба операнда.

`READ` принимает одно значение на строку: число, строку в кавычках, символ, массив, список или конструктор, например `Pair(1, "text")`. `WRITE` печатает по одному значению на строку. Числа хранятся в `long`, как в исходной реализации.

## Получение JSON с сайтов

Оба сайта принимают исходную программу в фигурных скобках в поле **Program text**. `eval.html` выдаёт AST, `sm.html` — скомпилированные инструкции. Например:

```text
{
  a = [1, 2, 3];
  a[1] += 5;
  s = "abc";
  s[0] = 'z';
  value = Pair(a, s);
  write(value);
  write(value.length);
  write(a[1]);
  write(s[0]);
  write(0 : {1, 2});
  for (i = 0; i < 2; i += 1) write(i);
}
```

В **Input** укажи `0`, если программе не нужен ввод: эталонный скрипт может не принять пустое поле. Нажми **Run**, затем **Download** под **JSON representation**. Сохрани результат как `program.json` в каталоге нужного проекта для AST либо как `instructions.json` в каталоге проекта машины.

Парсеры проекта читают полученный JSON; лексический и синтаксический разбор исходного языка выполняют сайты.

## Запуск

Из корня репозитория:

```powershell
dotnet build Simple-AST-Interpreter.slnx
```

Для запуска перейди в каталог соответствующего проекта, чтобы приложение нашло `program.json` или `instructions.json`, и выполни `dotnet run`.
